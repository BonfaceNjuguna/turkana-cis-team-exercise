# Task 0: getting started (everyone)

**Goal:** everyone can run the project, and has made one small pull request through the full workflow.

## Steps

1. Accept the invitation to the repository on GitHub.
2. Clone it and run the backend and frontend by following the [README](../../README.md). Open:
   - http://localhost:5173: the starter app, with a page for each task;
   - http://localhost:8000/docs: the API documentation. Try `GET /api/health`.
3. Create a branch `task-0/add-<your-name>`.
4. Add a line about yourself to [TEAM.md](../../TEAM.md): your name, your GitHub username, and which task you will lead or work on.
5. Commit, push, and open a pull request.
6. Review **one teammate's** Task 0 pull request and approve it once you have checked it.
7. Merge your own pull request after it is approved.

Several people editing the same file (`TEAM.md`) at once is deliberate: the later pull requests will need to bring in `main` and resolve a small conflict. See [CONTRIBUTING.md, section 4](../../CONTRIBUTING.md#4-keeping-your-branch-up-to-date).

## Then agree the plan

As a team, decide:

- who leads each of Tasks 1–3, and who helps;
- how each task will be split into pull requests (create an issue for each part);
- when you will check in with each other.

Write the plan in the Task 1–3 issues.

## Done when

- [ ] Everyone's line is in `TEAM.md` on `main`, each through a reviewed pull request
- [ ] Everyone has reviewed at least one pull request
- [ ] Each of Tasks 1–3 has a lead and a list of smaller issues
